# 💈 Barber SaaS - Sistema de Agendamento para Barbearias

Plataforma SaaS multi-tenant desenvolvida para gestão de barbearias e agendamento de serviços online para clientes.

## 🚀 Tecnologias Utilizadas

- **Mobile:** React Native com Expo e TypeScript
- **Estilização:** StyleSheet nativo
- **Versionamento:** Git & GitHub

## 📱 Funcionalidades (Em Desenvolvimento)

- [x] Interface de seleção de serviços e valores
- [ ] Seleção de barbeiro e horário
- [ ] Confirmação de agendamento
- [ ] Painel do barbeiro / gestão de agenda
- [ ] Programa de fidelidade

## 🛠️ Como executar o projeto localmente

```bash
# Clone o repositório
git clone [https://github.com/SeuUsuario/barber-saas.git](https://github.com/SeuUsuario/barber-saas.git)

# Entre na pasta do aplicativo mobile
cd barber-saas/mobile

# Instale as dependências
npm install

# Execute o servidor do Expo
npx expo start
